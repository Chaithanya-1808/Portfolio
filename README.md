# Chaithanya C — Editorial Portfolio Landing Page

An exact 1:1 replica of the high-fashion editorial Pinterest landing page inspiration, crafted in **React** with **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**, featuring **Chaithanya C** at the center of the design.

---

## 🌟 Restored Features & Exact Visual Elements

1. **Exact 1:1 Inspiration Layout**:
   - Warm luxury paper tone (`#F4F2EE`).
   - High-contrast editorial serif typography (`Bodoni Moda`, `Playfair Display`, `Cormorant Garamond`).
   - **Original "ausi" branding** in the top-left corner (with click-to-toggle option).
   - **Oversized pale background typography** (`Chaithanya` / `Steve J`) spanning behind the headline and imagery with delicate `#ebe7de` tone.

2. **Hero Section**:
   - Number counter: **`01`**
   - Main headline: **`Chaithanya C`** in bold, editorial serif typography.
   - Subtitle: **`genious or liar`** (click to toggle tagline).
   - Navigation links: **`< previous`** and **`next >`** with dot indicators and keyboard arrow support (`←` / `→`).
   - Original portrait placement on the right, seamlessly blending into the canvas and bottom bar.
   - Floating story card with accent line `—`, excerpt text, and rounded diagonal arrow button **`↗`** opening the full story modal.

3. **Original Black Inspiration Bar at Bottom**:
   - Sleek dark frosted glassmorphic bottom bar.
   - Left **`more >`** button opening the featured project showcase drawer.
   - 4 circular thumbnail items matching the inspiration:
     1. `Harper bams` (`suggestion >`)
     2. `Harpeer bames` (`suggestion >`)
     3. `Sequence` (`Shifter >`)
     4. `Ruffled` (`sleeves >`)
   - Right action button for instant access to highlights.

4. **Preserved Multi-Slide Showcase**:
   - Slide 01: **Chaithanya C** (Personal portfolio)
   - Slide 02: **Steve Jobs** (1:1 Original reference replica)
   - Slide 03: **Harper Bams** (Design system)
   - Slide 04: **Sequence Shifter** (Interactive engine)
